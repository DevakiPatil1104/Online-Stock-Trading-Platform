# Tradesphere - Full-Stack MERN Trading Platform

---

## Overview

TradeSphere is a full-stack trading platform built using the MERN stack. It allows users to explore stocks, manage portfolios, and simulate trading through a clean and responsive interface inspired by modern fintech applications.

---

## Tech Stack

* **Frontend:** React.js
* **Dashboard:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Testing:** Jest, React Testing Library
* **Charts:** Chart.js

---

## Features

* User Authentication (Login/Register)
* Interactive Dashboard
* Simulated Stock Trading
* Portfolio & Holdings Management
* Order Tracking
* Responsive UI
* Component Testing
